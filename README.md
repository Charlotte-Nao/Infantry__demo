# RoboMaster Infantry Demo (步兵机器人底层控制代码)

## 1. 项目简介
本项目是一个基于 STM32F407 芯片和 FreeRTOS 实时操作系统的 RoboMaster 步兵机器人底层控制框架。项目采用模块化、分层的设计思想，并使用 CMake 构建系统，方便在 CLion、VS Code 等现代 IDE 中进行高效开发。

## 2. 硬件平台
* **主控芯片**：STM32F407XX（大疆官方开发板 C 型）
* **惯性导航**：BMI088 (加速度计+陀螺仪) + IST8310 (磁力计)
* **执行机构**：大疆无刷直流电机（M3508, GM6020, M2006 等，通过 CAN 总线通信）
* **遥控接收**：大疆 DR16 遥控器接收机 (DBUS/UART 通信)

---

## 3. 系统分层架构 (Layered Architecture)
项目代码采用了严格的四层分层设计，以实现“高内聚、低耦合”，确保硬件驱动与上层控制逻辑分离：

1. **硬件外设与 HAL 库层 (`Core/`)**
   * 由 STM32CubeMX 生成的最底层代码。负责寄存器配置、时钟树、中断向量表（`stm32f4xx_it.c`）等基础支持。
2. **板级支持包 BSP 层 (`Bsp/`)**
   * 赋予 HAL 库业务含义。例如 `bsp_can.c` 包含专门接收大疆电机反馈的 CAN 过滤器；`bsp_uart.c` 配置了空闲中断+DMA用于接收遥控器不定长数据。
3. **硬件组件驱动层 (`Components/`)**
   * 对应具体物理模块：`motor` 负责解析电机 CAN 反馈报文；`remote` 负责解析 DR16 的 18 字节 DBUS 协议；`BMI088`/`ist8310` 负责读取 IMU 原始数据。
4. **操作系统与应用任务层 (`ALL_Task/`, `Application/`)**
   * 机器人的“大脑”，由 FreeRTOS 调度，各线程各司其职，通过全局变量或消息队列通信。

---

## 4. 核心任务解析 (`ALL_Task/`)
FreeRTOS 下运行的核心线程，决定了机器人的实时行为：

* **`sensor_task` (传感器与姿态解算任务)**：高频运行。读取 IMU 数据，调用 `Algorithm/MahonyAHRS` 进行互补滤波解算，输出机器人当前的 Pitch、Yaw 和 Roll 角。
* **`recv_cmd_task` (指令接收与状态机)**：汇总遥控器与视觉上位机的指令，切换机器人模式（如：底盘跟随、小陀螺、自瞄），并下发期望速度和角度。
* **`chassis_task` (底盘控制任务)**：接收期望平移和旋转速度，通过**麦克纳姆轮运动学逆解算**转化为四轮期望转速，经过 PID 计算得出目标电流。
* **`gimbal_task` (云台控制任务)**：采用**角度-速度串级 PID**，控制 Yaw 和 Pitch 轴跟随期望姿态。
* **`shoot_task` (发射机构任务)**：控制摩擦轮转速（射速）和拨弹电机旋转（射频），包含卡弹反转处理逻辑。
* **`motor_task` (电机统一发送任务)**：将上述任务计算出的目标电流打包，通过 CAN 总线统一下发给所有电调（ESC），避免总线拥堵。

## 5. 数据流向示例：从遥控器到电机
以 **“操作手向前推摇杆，机器人前进”** 为例的系统反射弧：

1. **【感知】**：操作手推摇杆，DR16 接收机将无线电信号通过 DBUS 协议发给 STM32。
2. **【底层触发】**：STM32 串口发生 DMA 接收中断，保存 18 字节数据。
3. **【数据解析】**：`remote.c` 拆包，算出摇杆通道值（如 Y轴偏移）。
4. **【意图转换】**：`recv_cmd_task.c` 将通道值转换为底盘期望前进速度 (Vx)。
5. **【运动学解算】**：`chassis_task.c` 拿 Vx 进行麦轮解算，得出四个轮子的目标转速。
6. **【闭环控制】**：`chassis_task.c` 读取电机实际转速，与目标转速进行 PID 计算，得出目标电流值。
7. **【执行输出】**：`motor_task.c` 将 4 个电流值打包进一个 CAN 标准帧并发送。
8. **【动作】**：电调（ESC）收到报文，输出三相电流驱动电机转动，机器人前进。

## 6. 高级工程特性
* **集成 CMSIS-DSP 库**：在 `Drivers/CMSIS/DSP/` 中引入了 ARM 官方的 DSP 库。利用 STM32F407 的硬件 FPU（浮点运算单元）处理高频矩阵运算、卡尔曼滤波和 PID 计算，极大降低 CPU 负载。
* **应用与算法剥离**：高级业务逻辑（如视觉自瞄装甲板、弹道下坠补偿、自动控制状态机）被提取在 `Application/auto_ctrl.c` 和 `robot_global.c` 中，保持核心任务代码整洁。

## 7. 开发环境与编译
本项目原生支持 CMake 构建，推荐使用跨平台、支持智能代码补全的 **CLion** 或 **VS Code** 进行开发。

### 依赖环境
* **底层配置**：STM32CubeMX (修改硬件配置请打开 `Infantry_01.ioc`)
* **工具链**：`arm-none-eabi-gcc`
* **构建工具**：CMake + Make/Ninja

### 编译步骤 (命令行示例)
```bash
# 1. 创建构建目录
mkdir build && cd build

# 2. 生成构建文件
cmake .. -DCMAKE_TOOLCHAIN_FILE=../cmake/gcc-arm-none-eabi.cmake

# 3. 编译工程
make -j8
```
